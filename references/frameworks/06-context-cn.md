# 中文语境与常见偏差

## 为什么单列一份

上面五个框架的原始研究，样本绝大多数是**西方、已婚、异性恋、中产**。
直接套到中国的微信聊天上，会有系统性偏差。这份文件用来校正。

## 四个语境差异

### 1. 婚恋压力是背景音，不是关系本身

「36 岁了」「家里催」「再拖就来不及」这类叙事会渗透进聊天，
让一段普通的关系承载「最后一次机会」的重量。
分析时要区分：**这段关系的问题**，和**她对时间的焦虑**。

误判示范：把「他很冷淡」解释成「他不爱你」，其实可能是「你急需一个答案，而他只是慢」。

### 2. 家庭介入的权重不同

在集体主义语境里，「父母怎么看」「要不要带回家」是关系阶段的重要指标，
有时比「我们算什么」更能说明进度。西方量表里这一项权重很低。

### 3. 相亲/婚恋市场的条件交换逻辑

条件（户口、房、收入、年龄）在初期就会被摆上台面，
这与「先心动再谈条件」的西方约会脚本不同。
看到「他问我做什么工作、有没有房」时，不要立刻判为功利——
那可能只是这个市场的默认开场。

### 4. 微信作为媒介的特性

- **异步**：回复慢不等于冷淡，可能只是在上班
- **无已读**：看不到对方是否已读，所有「已读不回」的推断都是猜的
- **可编辑**：发出去的话是改过的，撤回消息（记录里常出现）说明有反复
- **表情包承担语气**：一句话配什么表情，意思可能完全相反
- **语音**：语音往往比文字更放松，语气信息在文字里会丢失

## 五个必须警惕的分析偏差

| 偏差 | 表现 | 校正 |
|---|---|---|
| **单方视角** | 只有一方的记录，把「他没说」当成「他没想」 | 所有推断标注「从他的行为看」，不写「他心里想」 |
| **确认偏误** | 用户已经认定「他不爱我」，记录会被读成证据 | 强制列出反方向证据，至少 3 条 |
| **可得性偏差** | 最近一次冲突权重过高 | 按周/月统计，不按最后一天下结论 |
| **归因错误** | 对方的行为归因于人品，自己的行为归因于处境 | 对双方使用同一套归因标准 |
| **理论套用** | 用「回避型依恋」解释一切退缩 | 一个构念最多解释一类行为，不能解释全部 |

## 语言层面的坑

- **反讽与撒娇**：「你是不是傻」在亲密关系里常常是亲昵，不是攻击。看上下文和表情。
- **方言与网络语**：「整挺好」「夺命镰刀」这类要按关系内部的语汇理解，不要按字面。
- **语音转写错误**：ASR 会把「富联」转成「复联」、「兆易」转成「赵育」。引用时照抄原文，但解读时按上下文修正。
- **撤回消息**：记录里出现「你撤回了一条消息」，说明有反复斟酌，这是信息，不是噪音。
